# 📚 كوميكس عربية - موقع نشر وقراءة الكوميكس

موقع متكامل لنشر وقراءة القصص المصورة (الكوميكس) باللغة العربية.

## 🌟 المميزات

- تصميم عصري بثيم داكن/فاتح مع إمكانية التبديل
- واجهة متجاوبة بالكامل (موبايل، تابلت، كمبيوتر)
- دعم كامل للعربية مع اتجاه RTL
- قارئ كوميكس بملء الشاشة مع تكبير/تصغير
- نظام فصول مع حفظ موضع القراءة
- تقييم بالنجوم وعدّاد مشاهدات
- لوحة تحكم متكاملة للمدير
- تصنيفات وبحث فوري

## 📁 هيكل المشروع

comicx/

## 🚀 كيفية الاستخدام

### 1. التشغيل المحلي

بما أن الموقع يعمل بـ JavaScript فقط (بدون خادم)، يمكنك فتح أي صفحة مباشرة في المتصفح:

```bash
# فتح الصفحة الرئيسية
start index.html

# أو باستخدام Live Server في VS Code
# اضغط كليك يمين على index.html → Open with Live Server
```

### 2. بيانات الدخول الافتراضية

```
اسم المستخدم: admin
كلمة المرور: admin123
```

⚠️ **مهم:** غيّر كلمة المرور فوراً من لوحة التحكم → الإعدادات

## 🌐 الاستضافة المجانية

### الخيار 1: Vercel (الأفضل)

```bash
# 1. تثبيت Vercel CLI
npm install -g vercel

# 2. الدخول لمجلد المشروع
cd comicx

# 3. النشر
vercel

# 4. اتبع التعليمات على الشاشة
```

**أو عبر GitHub:**
1. أنشئ مستودعاً على GitHub
2. ارفع الملفات
3. اذهب إلى vercel.com
4. اربط حسابك بـ GitHub
5. اختر المستودع واضغط Deploy

### الخيار 2: Netlify

1. اذهب إلى netlify.com
2. سجل الدخول بحساب Google/GitHub
3. اسحب مجلد المشروع وأفلته في المنطقة المخصصة
4. سيتم النشر فوراً مع رابط مجاني

### الخيار 3: GitHub Pages

1. أنشئ مستودعاً على GitHub باسم `yourusername.github.io`
2. ارفع جميع الملفات
3. اذهب إلى Settings → Pages
4. اختر Branch: main
5. سيتم النشر على رابط: `https://yourusername.github.io`

## 📝 دليل لوحة التحكم

### إضافة كوميكس جديد
1. سجل الدخول من `admin/login.html`
2. اذهب إلى "الكوميكس" → "إضافة كوميكس جديد"
3. أدخل العنوان والوصف والتصنيف
4. أدخل رابط صورة الغلاف (من Imgur أو أي موقع)
5. احفظ

### إضافة فصل جديد
1. اذهب إلى "الفصول" → "إضافة فصل جديد"
2. اختر الكوميكس
3. أدخل رقم الفصل والعنوان
4. اسحب الصور وأفلتها في منطقة الرفع (Drag & Drop)
5. احفظ

### رفع الصور
يمكنك استخدام مواقع رفع الصور المجانية:
- **Imgur:** https://imgur.com
- **Free Image Hosting:** https://freeimage.host
- **ImgBB:** https://imgbb.com

### إضافة تصنيفات
1. اذهب إلى "التصنيفات"
2. أدخل اسم التصنيف واضغط "إضافة"
